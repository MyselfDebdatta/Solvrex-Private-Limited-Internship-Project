# Impact Atlas

Build a premium, production-grade frontend prototype for a modern Indian social-impact NGO.

IMPORTANT CONTEXT

This is a frontend-only concept/prototype being evaluated by the executive leadership of a technology company. It must look like a serious, scalable NGO platform that could eventually serve thousands or millions of users.

This is NOT a generic charity landing page.

The objective is to demonstrate a complete, thoughtful digital product vision for a future NGO platform.

The core brand philosophy is:

"MAKE IMPACT VISIBLE."

The website should communicate:

Problem → Community → Action → Progress → Measurable Impact → Participation

The design should combine:

- premium modern NGO aesthetics

- editorial storytelling

- trustworthy institutional design

- data visualization

- human-centered photography

- subtle high-quality motion

- excellent UX

- accessibility

- responsive design

- scalable component architecture

Do not make it look like a student project or a generic AI-generated NGO template.
